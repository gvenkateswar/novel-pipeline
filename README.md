# Novel Pipeline

Agentic writing pipeline using Claude Code subagents. Produces a novel or novella chapter by chapter through a structured generate → critique → revise loop.

## Repo structure

```
novel-pipeline/
├── CLAUDE.md                    ← orchestrator instructions (read first)
├── README.md                    ← this file
├── story-bible.md               ← source of truth — fill before drafting
├── outline.md                   ← chapter breakdown — generated by story-architect
├── continuity-log.md            ← updated after every chapter
├── research/
│   ├── market-analysis.md       ← generated by market-analyst
│   └── niche-proposals.md       ← generated by niche-spotter
├── chapters/
│   └── chapter-01/
│       ├── beats.md             ← generated by plot-architect
│       ├── draft.md             ← generated by prose-writer
│       ├── issues.md            ← generated by continuity-checker
│       ├── draft-revised.md     ← generated by prose-writer (revision pass)
│       └── final.md             ← generated by voice-editor
└── .claude/
    └── agents/
        ├── market-analyst.md
        ├── niche-spotter.md
        ├── story-architect.md
        ├── plot-architect.md
        ├── prose-writer.md
        ├── continuity-checker.md
        └── voice-editor.md
```

## How to run

Open a Claude Code session with this repo attached. Then:

### Phase 1 — Research (run once)
```
Run research phase
```
Fires market-analyst and niche-spotter in parallel. Review `research/` output and pick a direction.

### Phase 2 — Setup (run once after research)
```
Run setup phase
```
Fires story-architect to build the full chapter outline. Review and approve `outline.md` before drafting.

### Phase 3 — Fill story-bible.md
Fill in characters, world, settings, and style reference before writing chapter 1.
The pipeline agents read this file on every chapter run.

### Phase 4 — Drafting (run per chapter)
```
Run chapter 1 pipeline
Run chapter 2 pipeline
...
```
Each chapter run produces a `final.md` in its folder and appends to `continuity-log.md`.

### Revision commands
```
Run just the voice edit on chapter 3
Check continuity on chapter 5
Run chapters 4 through 6
```

## Your manuscript

Copy each `chapters/chapter-XX/final.md` into your master manuscript document (Google Docs, Word, etc.) after approving it. The pipeline doesn't maintain a single assembled file — you do the final assembly and human editing pass.

## Agents

| Agent | Role | Runs |
|-------|------|------|
| market-analyst | Genre research, reader demand | Once (research phase) |
| niche-spotter | Story angle proposals | Once (research phase) |
| story-architect | Full chapter outline | Once (setup phase) |
| plot-architect | Scene beat sheet per chapter | Per chapter |
| prose-writer | Draft prose + revision pass | Per chapter (twice) |
| continuity-checker | Validation against story bible | Per chapter |
| voice-editor | Final voice and line edit | Per chapter |
