# Novel Pipeline

Agentic writing pipeline using Claude Code subagents. Produces a novel or novella chapter by chapter through a structured generate → critique → revise loop.

## Repo structure

```
novel-pipeline/
├── CLAUDE.md                    ← orchestrator instructions (read first)
├── README.md                    ← this file
├── story-bible.md               ← source of truth — approved before drafting
├── story-bible-draft.md         ← generated by bible-builder for your approval
├── outline.md                   ← chapter breakdown — generated by story-architect
├── continuity-log.md            ← updated after every chapter
├── research/
│   ├── market-analysis.md       ← generated by market-analyst
│   └── niche-proposals.md       ← generated by niche-spotter
├── chapters/
│   └── chapter-01/
│       ├── beats.md             ← generated by plot-architect
│       ├── draft.md             ← generated by prose-writer
│       ├── issues.md            ← generated by continuity-checker
│       ├── draft-revised.md     ← generated by prose-writer (revision pass)
│       ├── final.md             ← generated by voice-editor
│       └── reader-notes.md      ← generated by cold-reader
└── .claude/
    └── agents/
        ├── market-analyst.md
        ├── bible-builder.md
        ├── cold-reader.md
        ├── niche-spotter.md
        ├── story-architect.md
        ├── plot-architect.md
        ├── prose-writer.md
        ├── continuity-checker.md
        └── voice-editor.md
```

## How to run

Open a Claude Code session with this repo attached. Then:

### Phase 1 — Research (run once)
```
Run research phase
```
Runs market-analyst, then niche-spotter. Review `research/niche-proposals.md` and pick an angle.

### Phase 2 — Setup (run once after research)
```
Run setup phase with angle 3
```
story-architect builds the outline; you approve it. bible-builder then drafts the story bible into `story-bible-draft.md`; you edit and approve it, and it becomes `story-bible.md`.

### Phase 3 — Add style samples
Paste 3–5 paragraphs from published books you want the prose to sound like into the Style Reference section of `story-bible.md`. Do this before chapter 1.

### Phase 4 — Drafting (run per chapter)
```
Run chapter 1 pipeline
Run chapter 2 pipeline
...
```
Each chapter run produces a `final.md` and a cold reader's `reader-notes.md` in its folder, and adds an entry to `continuity-log.md`. Read the reader notes. They are the best signal for what to revise.

### Revision commands
```
Run just the voice edit on chapter 3
Check continuity on chapter 5
Run chapters 4 through 6
Cold read chapter 4
Run manuscript read
```

## Your manuscript

Copy each `chapters/chapter-XX/final.md` into your master manuscript document (Google Docs, Word, etc.) after approving it. The pipeline doesn't maintain a single assembled file — you do the final assembly and human editing pass.

## Agents

| Agent | Role | Model | Runs |
|-------|------|-------|------|
| market-analyst | Genre research, reader demand | Sonnet | Once (research) |
| niche-spotter | Story angle proposals | Sonnet | Once (research) |
| story-architect | Full chapter outline | Opus | Once (setup) |
| bible-builder | Drafts characters, world, settings | Opus | Once (setup) |
| plot-architect | Scene beat sheet per chapter | Opus | Per chapter |
| prose-writer | Draft prose + revision pass | Opus | Per chapter (twice) |
| continuity-checker | Validation against story bible | Sonnet | Per chapter |
| voice-editor | Final voice and line edit | Sonnet | Per chapter |
| cold-reader | Reads finished chapters with no planning files | Opus | Per chapter + once at end |
